# HoopEval_vis_2

This project is configured for GitHub Pages deployment from the `main` branch through GitHub Actions.

## Local development

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

Push to `main`, then GitHub Actions will build the Vite app and publish `dist/` to GitHub Pages automatically.

Repository Pages URL:

```text
https://mr81wx.github.io/HoopEval_vis_2/
```

## GitHub repository settings

In GitHub:

1. Open `Settings -> Pages`.
2. Set `Source` to `GitHub Actions`.
3. Save once if this repository has not used Pages before.
